# 技能：网申填表（apply_form）

> 触发词：网申、投递、填表、保存简历、改岗

## 前置检查
1. 浏览器已登录目标站（用 Playwright connectOverCDP 复用登录态）。
2. 已确认岗位/志愿状态（是否已满、限投次数）。
3. 简历版本确定。

## 标准步骤
1. **读结构**：一次性列出所有字段（标签/值/是否禁用），**不猜顺序**。
2. **批量写**：同一区块一次写完（`fill` / `select_option` / `set_input_files`）。
3. **勾选同意**：保存/提交前必须勾「我已阅读并同意…隐私政策」。
4. **保存并验证**：抓到写接口 `2xx` 且响应 `status=1`（或等价成功标识）才算成功。
5. **刷新回读**：reload 后字段值一致，才 PASS。
6. **写断点**：`python tools/checkpoint.py set "..."`；产出回执到 `out/receipt_<T号>.md`。

## 红线
- 登录 / 验证码 / **最终提交**由用户完成。
- 不伪造字段值；不确定的留空并报告。
- 连续失败 2 次即停。

## 实证坑
| 坑 | 现象 | 解法 |
|---|---|---|
| 未勾隐私政策 | 点保存无任何网络请求 | 先勾方框 |
| 只读预览态 | 字段读不到 | 先点「编辑」进 edit 模式 |
| SPA 卡片 | 点文本无反应 | 用 Playwright 文本定位 + auto-wait |
| antd 下拉 | JS click 无效 | `select_option` |
| 上传 | 设错 input | 逐个 input 试并校验页面文件名变化 |
